# Compact details design previews

Four standalone alternatives at `/design-options/details-compact-options.html`:

- Studio: map and activity overview in a compact grid.
- Lens: persistent map beside a sequential activity column.
- Focus: one selected section with a curtain reveal and staggered content.
- Folio: compact editorial sections and a scroll-progress line.

Shared palette: blue-grey #e3eaf4 / navy #101827, original Plex Arabic typography. Intro headings max 42px. Native Web Animations handle text masking, architectural stroke reveal, panel transitions and staggered entrance; reduced-motion and pause controls are included. No borrowed photos, video, external animation dependencies or account data. Existing map viewer/engine is reused.

Browser verification: four designs at 1440, 390 and 320px (reduced motion at 320), map canvas and controls, selected pin text fitting without nested scrolling, theme synchronization, section navigation, operations dialog / Escape, five quick links, pause/resume, and no page overflow or JavaScript errors. Comparison gallery selection and play/stop demo tested for every design; mobile gallery also checked. Local preview links resolve and actual details content destinations are retained.

An AGY attempt for an isolated decorative SVG timed out and created no asset; Codex authored and reviewed the artwork locally. Actual application routes and map source were not edited by this task. These are selectable prototypes, not a production deployment or authenticated account-flow test.
