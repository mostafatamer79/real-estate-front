Shared direction: high-end immersive architectural portfolio aesthetic; pearl stone, royal navy and restrained desert gold; clear depth and crop-safe focal point; each scene different from the existing residence facade. Source PNGs remain in the image generation output directory. Workspace WebP assets total roughly 0.9 MB before Next image resizing.

`AnimatedArtwork` implements slow camera drift, small desktop pointer parallax and scroll response. It pauses offscreen and when the document is hidden, disables movement for reduced-motion users, and keeps native form/pointer/scroll behavior. The actual neighborhood scene remains interactive Three.js. Raster camera movement is not a rendered 3D model or generated video.
